# رفيق المدرس — Tutor Buddy

تطبيق ويب (PWA) يتثبت على الموبايل لإدارة طلاب المدرس الخصوصي: مجموعات، حصص، حضور وغياب، درجات، امتحانات، مصاريف، ملفات، إشعارات، وتقارير واتساب.

- Backend: Supabase project `rafiq-modares` (جداول app_docs و push_subs، bucket اسمه files، edge function اسمها push-alerts بتشتغل كل 10 دقايق).
- الاستضافة: أي استضافة static بـ HTTPS (GitHub Pages / Netlify).
